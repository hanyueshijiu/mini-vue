# Mini Vue：结合源码，逐步手写 Vue 核心

一个循序渐进的 Vue 3 源码学习项目。使用 JavaScript 手写可运行的简化实现，通过行为验收和问答复盘理解设计，再对照官方 TypeScript 源码。

每节课保留独立的练习、参考实现和学习记录，便于比较不同阶段的变化。课程讲解、示例、习题答案与源码阅读入口统一放在各课的 README 中。

## 快速开始

需要 Node.js 22 或更高版本。当前没有第三方运行依赖，无需 npm install。

```bash
git clone https://github.com/hanyueshijiu/mini-vue.git
cd mini-vue
npm test
```

`npm test` 验收已提交的手写实现与参考实现。学习和复习状态见课程导航，单课运行方式见对应课程 README；使用 `npm run` 查看可用命令。

## 目录约定

根目录维护项目介绍、运行命令和通用配置。课程按编号放在独立目录中，通常包含：

| 文件 | 用途 |
| --- | --- |
| README.md | 本课目标、实现过程、运行方法、复习题与源码对照 |
| practice.mjs | 手写练习及学习注释 |
| reference.mjs | 对应阶段的参考实现 |
| check*.mjs | 行为验收脚本 |
| *demo.mjs | 按需提供的演示与问题复现 |

各课实现独立维护，使用时请成套导入同一课的模块。

## 学习方式

1. 阅读当前课程的 README，先理解要解决的问题和预期行为。
2. 在 practice.mjs 中独立实现，再运行该课的验收脚本。
3. 根据失败用例检查调用顺序、数据结构和状态变化。
4. 对照参考实现及官方源码，解释设计选择。
5. 完成复习题，把容易混淆的场景记录在本课 README 中。

已有解答的练习可在本地副本中重新实现，保留已完成的学习记录用于对照。

## 源码基线与项目范围

官方源码阅读固定在 [Vue v3.5.42](https://github.com/vuejs/core/tree/v3.5.42)，避免跟随分支变化导致阅读位置和实现差异。

这是用于学习的分阶段实现，尚不具备完整框架的功能与边界处理能力。每个阶段的支持范围、简化之处和待解决问题，以对应课程 README 为准。
